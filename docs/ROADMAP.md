# Rosaline Roadmap

The roadmap favors a small set of dependable, thoroughly documented features.

## v0.1 — Foundation

- [x] Application window
- [x] Labels and buttons
- [x] Rows and columns
- [x] Simple state
- [x] Canvas primitives
- [x] Themes and colors
- [x] Quick Start
- [x] Runnable examples

## v0.2 — Forms and input

- [x] TextBox and TextArea
- [x] CheckBox
- [x] Radio groups
- [ ] Keyboard events and shortcuts
- [x] Focus and tab navigation
- [x] Basic validation patterns and beginner-friendly form documentation

## v0.3 — Interactive canvas

- [x] Mouse position and button events
- [x] Click-and-drag input
- [x] Shift, Control, and Alt mouse modifiers
- [x] Automatic canvas redraw after input
- [x] Explicit redraw from other callbacks
- [x] Runnable paint example and beginner guide

## v0.4 — Real application building

- [x] Images and image loading
- [x] Scroll areas
- [x] Menus and shortcuts
- [x] Open and save dialogs
- [x] Confirmation and error dialogs
- [x] Complete image-viewer application
- [x] Timers and animation

## v0.5 — Drawing applications

- [x] Paths and Bézier curves
- [x] Transforms: translate, rotate, and scale
- [x] Clipping
- [x] Basic canvas redraw/invalidation
- [x] Off-screen images
- [x] PNG and AVIF image export

## v0.6 — Larger interfaces

- [x] Lists
- [x] Tabs
- [x] Tables
- [x] Trees
- [x] Multiple windows
- [ ] Custom widgets
- [ ] Accessibility groundwork
- [ ] HiDPI and multi-monitor test suite
- [ ] Native Wayland backend investigation

## v0.10 — Everyday controls

- [x] Radio groups
- [x] Read-only combo boxes
- [x] Numeric sliders
- [x] Determinate progress bars
- [x] Indeterminate busy progress
- [x] Dynamic options and choices
- [x] Complete Task Settings application

# Rosaline Roadmap

The roadmap favors a small set of dependable, thoroughly documented features.

## v0.1 — Foundation

- [x] Application window
- [x] Labels and buttons
- [x] Rows and columns
- [x] Simple state
- [x] Canvas primitives
- [x] Themes and colors
- [x] Quick Start
- [x] Runnable examples

## v0.2 — Forms and input

- [x] TextBox and TextArea
- [x] CheckBox
- [ ] RadioButton
- [ ] Keyboard events and shortcuts
- [ ] Mouse events for Canvas
- [x] Focus and tab navigation
- [x] Basic validation patterns and beginner-friendly form documentation

## v0.3 — Real application building

- [ ] Images and image loading
- [ ] Scroll areas
- [ ] Menus
- [ ] Open and save dialogs
- [ ] Confirmation dialogs
- [ ] Timers and animation

## v0.4 — Drawing applications

- [ ] Paths and Bézier curves
- [ ] Transforms: translate, rotate, and scale
- [ ] Clipping
- [ ] Canvas redraw/invalidation
- [ ] Off-screen images
- [ ] Image export

## v0.5 — Larger interfaces

- [ ] Lists, tables, tabs, and trees
- [ ] Multiple windows
- [ ] Custom widgets
- [ ] Accessibility groundwork
- [ ] HiDPI and multi-monitor test suite
- [ ] Native Wayland backend investigation

## Documentation applications
